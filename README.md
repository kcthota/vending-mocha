# kcthota.com

This is the source code for my personal portfolio and blog built with React, TypeScript, and Vite.

## Features

- **Blog**: Markdown-based blog posts using `react-markdown` and `gray-matter` for frontmatter parsing.
- **Projects Showcase**: A section to display various projects with status indicators:
  - 🚀 Active
  - 💀 Dead
  - 🦥 Inactive
- **Responsive Design**: Clean and modern layout.

## Getting Started

1.  **Install dependencies:**

    ```bash
    npm install
    ```

2.  **Run the development server:**

    ```bash
    npm run dev
    ```

## Scripts

- `npm run dev`: Starts the development server.
- `npm run build`: Builds the main application for production.
- `npm run build:all`: Builds the main application and all sub-projects located in the `projects/` directory.
- `npm run preview`: Locally preview the production build.
- `npm run lint`: Runs ESLint to check for code quality issues.
